## 🟢 Level 2 — Text Formatting

HTML Text Formatting is used to change the appearance and meaning of text, such as **Bold, Italic, Highlight, Deleted, Inserted, Subscript,** and **Superscript**.

### 📚 Topics Covered

| #  | HTML Tag   | Description      |
| -- | ---------- | ---------------- |
| 11 | `<b>`      | Bold text        |
| 12 | `<strong>` | Important text   |
| 13 | `<i>`      | Italic text      |
| 14 | `<em>`     | Emphasized text  |
| 15 | `<mark>`   | Highlighted text |
| 16 | `<small>`  | Small text       |
| 17 | `<del>`    | Deleted text     |
| 18 | `<ins>`    | Inserted text    |
| 19 | `<sub>`    | Subscript text   |
| 20 | `<sup>`    | Superscript text |

### 🔹 11. `<b>` — Bold

The `<b>` tag makes text **bold**.

```html
<p>This is <b>bold text</b>.</p>
```

**বাংলা:** `<b>` tag কোনো লেখাকে মোটা বা **Bold** করে দেখায়।

---

### 🔹 12. `<strong>` — Important Text

The `<strong>` tag indicates that the text is **important**.

```html
<p><strong>Warning!</strong> Do not touch this button.</p>
```

**বাংলা:** `<strong>` tag দিয়ে কোনো গুরুত্বপূর্ণ text বোঝানো হয়।

---

### 🔹 13. `<i>` — Italic

The `<i>` tag displays text in *italic* style.

```html
<p>This is <i>italic text</i>.</p>
```

**বাংলা:** `<i>` tag লেখাকে *Italic বা বাঁকা* করে দেখায়।

---

### 🔹 14. `<em>` — Emphasized Text

The `<em>` tag is used to emphasize text.

```html
<p>You <em>must</em> complete this task.</p>
```

**বাংলা:** `<em>` tag কোনো text-কে বিশেষভাবে গুরুত্ব দিয়ে প্রকাশ করতে ব্যবহার করা হয়।

---

### 🔹 15. `<mark>` — Highlight

The `<mark>` tag highlights text.

```html
<p>This is <mark>important</mark> information.</p>
```

**বাংলা:** `<mark>` tag কোনো লেখাকে **Highlight** করে দেখায়।

---

### 🔹 16. `<small>` — Small Text

The `<small>` tag displays text smaller than the surrounding text.

```html
<p>This is <small>small text</small>.</p>
```

**বাংলা:** `<small>` tag সাধারণ text-এর তুলনায় ছোট আকারের text দেখায়।

---

### 🔹 17. `<del>` — Deleted Text

The `<del>` tag represents text that has been deleted.

```html
<p>Old Price: <del>$100</del></p>
```

**বাংলা:** `<del>` tag দিয়ে বোঝানো হয় যে কোনো text **Delete করা হয়েছে**।

---

### 🔹 18. `<ins>` — Inserted Text

The `<ins>` tag represents text that has been inserted or added.

```html
<p>New Price: <ins>$80</ins></p>
```

**বাংলা:** `<ins>` tag দিয়ে বোঝানো হয় যে কোনো নতুন text **যোগ করা হয়েছে**।

---

### 🔹 19. `<sub>` — Subscript

The `<sub>` tag displays text slightly below the normal text.

```html
<p>Water = H<sub>2</sub>O</p>
```

**Output:** H₂O

**বাংলা:** `<sub>` tag text-কে সাধারণ লেখার নিচে ছোট করে দেখায়।

---

### 🔹 20. `<sup>` — Superscript

The `<sup>` tag displays text slightly above the normal text.

```html
<p>2<sup>2</sup> = 4</p>
```

**Output:** 2² = 4

**বাংলা:** `<sup>` tag text-কে সাধারণ লেখার উপরে ছোট করে দেখায়।

---

### 🧠 Quick Reference

```text
<b>        → Bold
<strong>   → Important
<i>        → Italic
<em>       → Emphasized
<mark>     → Highlight
<small>    → Small text
<del>      → Deleted
<ins>      → Inserted
<sub>      → Subscript
<sup>      → Superscript
```
